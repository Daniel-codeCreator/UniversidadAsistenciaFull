4. Estructura de app/engine.py (Captura Frontal Simplificada)
Asegúrate de que el archivo app/engine.py tenga configurada la captura biométrica reducida únicamente a la fase frontal:

Python
def capture_enrollment(self, user_label: str = "Usuario") -> CaptureResult:
    phases = (
        EnrollmentPhase("FRENTE", "MIRE AL FRENTE", "front", self.settings.enroll_sample_count, "TIMEOUT_FRONT"),
    )
    logger.info("Enrollment phase=FRONT user_id_label=%s", user_label)
    return self._capture(
        sample_count=self.settings.enroll_sample_count,
        timeout_seconds=self.settings.enroll_timeout_seconds,
        title="Universidad Asistencia - Registro Facial",
        user_label=user_label,
        phases=phases,
    )
5. Primera Ejecución y Descarga del Modelo buffalo_l
La primera vez que arranques el backend, InsightFace descargará automáticamente los modelos requeridos (det_10g.onnx, w600k_r50.onnx, etc.) a la carpeta C:\Users\<usuario>\.insightface\models\buffalo_l.

Inicia el servicio desde PowerShell:

PowerShell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8765
Nota: Deja esta ventana abierta mientras ejecutes el enrolamiento o la aplicación Java.

Con el servidor API en ejecución en la Ventana 1, abre una segunda ventana de PowerShell para registrar la cara del usuario 1002 (o admin):
